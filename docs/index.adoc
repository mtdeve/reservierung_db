== Introduction
This project is a collection of some of my earliest Python exercises, originally written in 2015.

It was never intended to become a production-ready library. Instead, it served as a personal playground where I explored the fundamentals of combinatorics, factorials, permutations, and other mathematical concepts while learning Python.

Most of these exercises were inspired by my personal studies, mathematics books, and educational videos that I followed in my spare time.

In 2026, during my professional retraining in the IT field, I decided to create a repository for this old project, clean up the original code, and add some documentation. The purpose is to preserve them as a small collection of my first steps with Python. The original ideas and implementations have been mostly kept unchanged, including some mistakes and limitations that are part of the learning process.

The command-line interface has also been recently added in 2026 and is intentionally kept as simple as possible. It may be improved over time as the project is further studied and developed.
